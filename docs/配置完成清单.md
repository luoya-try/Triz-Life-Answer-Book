## 🚀 快速开始（3步完成配置）

### 第1步：获取 NVIDIA API 密钥

1. 访问 https://build.nvidia.com/
2. 注册/登录账户
3. 进入 API Keys 页面
4. 生成新的 API Key（格式：`nvapi-xxxx`）

### 第2步：更新配置文件

**方法1：手动编辑（推荐）**

1. 打开文件：`pages/questionnaire/config.js`
2. 找到第4行：
   ```javascript
   apiKey: 'nvapi-xxxx',
   ```
3. 替换为您的真实密钥：
   ```javascript
   apiKey: 'nvapi-你的真实密钥',
   ```
4. 保存文件

**方法2：告诉我密钥**

您可以直接将您的 NVIDIA API 密钥发送给我，我会帮你更新配置。

### 第3步：编译并测试

1. 在微信开发者工具中点击 **编译** 按钮
2. 进入"首页" → 点击"开始分析"
3. 在问卷页面输入问题答案
4. 观察状态栏是否显示"✓ 真实AI已响应"

## 🔧 切换模型

如需切换到其他模型：

1. 打开 `pages/questionnaire/config.js`
2. 修改第5行的 `model` 值：
   ```javascript
   model: 'mistralai/mistral-7b-instruct-v0.3',  // 切换到 Mistral 7B
   ```
3. 保存并编译

## ⚠️ 重要提醒

### 1. 域名检查已关闭
- ✅ 配置文件中已设置 `urlCheck: false`
- ✅ 本地开发无需配置域名白名单

### 2. 生产环境注意事项
- ⚠️ 发布前需在微信公众平台配置域名

- 🔒 不要将真实密钥提交到代码仓库
- 🔒 使用环境变量或配置文件管理
- 🔒 生产环境建议使用后端代理
