# 微信小程序域名配置指南

**适用场景**: 生产环境部署、上线审核前配置

---

## 一、前置条件

在配置域名白名单之前，请确保：

| 条件 | 要求 | 检查方式 |
|------|------|----------|
| 微信小程序已注册 | 完成注册并通过认证 | 微信公众平台登录 |
| AppID 已配置 | 项目中 `project.config.json` 已有正确的 appid | 检查文件 |
| 域名已备案 | 如果使用自有域名需备案 | 工信部备案查询 |

---

## 二、需要配置的域名

本小程序需要访问以下域名：

| 域名 | 用途 | 协议 | 端口 |
|------|------|------|------|
| `integrate.api.nvidia.com` | AI大语言模型API调用 | HTTPS | 443 |

---

## 三、配置步骤

### 步骤1：登录微信公众平台

1. 打开浏览器，访问：[微信公众平台](https://mp.weixin.qq.com/)
2. 使用小程序管理员账号登录
3. 进入 **开发 > 开发管理 > 开发设置 > 服务器域名**

### 步骤2：配置 request 合法域名

在 **request 合法域名** 部分添加：

```
https://integrate.api.nvidia.com
```

**操作说明**：

1. 点击 **编辑** 按钮
2. 在输入框中添加域名（每行一个）
3. 点击 **确认** 保存

**截图位置示意**：

```
┌─────────────────────────────────────────┐
│  服务器域名                              │
├─────────────────────────────────────────┤
│  request合法域名                         │
│  ┌─────────────────────────────────────┐│
│  │ https://integrate.api.nvidia.com   ││  ← 添加此项
│  └─────────────────────────────────────┘│
│                                         │
│  socket合法域名                         │
│  [暂不需要配置]                         │
│                                         │
│  uploadFile合法域名                     │
│  [暂不需要配置]                         │
│                                         │
│  downloadFile合法域名                   │
│  [暂不需要配置]                         │
└─────────────────────────────────────────┘
```

### 步骤3：保存并等待生效

1. 点击页面底部的 **保存** 按钮
2. 配置将在 **10分钟内** 生效
3. 无需重新发布小程序

## 四、常见问题

### Q1：配置后提示域名不合法？

**原因**：
- 域名输入错误
- 包含空格或特殊字符
- 未保存就生效

**解决**：
```bash
# 检查域名格式（正确示例）
https://integrate.api.nvidia.com

# 检查域名格式（错误示例）
https:// integrate.api.nvidia.com  # 有空格
integrate.api.nvidia.com           # 缺少https://
```

### Q2：开发环境需要配置吗？

**开发环境**：
- 使用微信开发者工具时，可在 **详情 > 本地设置** 中勾选：
  ```
  ✓ 不校验合法域名、web-view（业务域名）、TLS版本以及HTTPS证书
  ```

**生产环境**：
- 必须配置域名白名单
- 勾选 "不校验" 选项仅在开发环境有效

### Q3：配置后多久生效？

**实时生效**：保存后10分钟内
**验证方式**：使用真机调试测试API调用

### Q4：提示"request 合法域名校验出错"？

**错误信息**：
```
request 合法域名校验出错，请检查域名是否ICP备案
或域名格式是否正确
```

**解决方法**：
1. 检查域名拼写是否正确
2. 确认使用 HTTPS 协议
3. 确认域名可以正常访问（浏览器打开测试）

## 五、验证配置是否成功

### 方法1：微信开发者工具验证

1. 打开微信开发者工具
2. 导入项目
3. 在 **详情 > 本地设置** 中 **取消勾选** "不校验合法域名"
4. 点击 **编译**
5. 测试AI功能是否正常

### 方法2：真机调试验证

1. 在微信开发者工具中点击 **真机调试**
2. 等待二维码生成
3. 使用微信扫描二维码
4. 在真机上测试功能

### 方法3：控制台检查

打开微信开发者工具的控制台（Console），查看：
- ✅ `request:ok` 表示请求成功
- ❌ `request:fail` 表示域名配置可能有问题

## 六、代码配置检查

确认 `project.config.json` 中的配置：

```json
{
  "projectname": "TRIZ问题分析",
  "appid": "你的AppID",
  "setting": {
    "urlCheck": true,  // 生产环境应设为 true
    ...
  }
}
```

## 七、故障排查清单

| 检查项 | 状态 | 说明 |
|--------|------|------|
| 微信公众平台登录 | ☐ | 确认使用管理员账号 |
| 域名已添加到白名单 | ☐ | request合法域名列表 |
| 配置已保存 | ☐ | 点击保存按钮 |
| 等待10分钟生效 | ☐ | 配置不会立即生效 |
| 项目appid正确 | ☐ | project.config.json |
| 取消"不校验"选项 | ☐ | 开发工具本地设置 |

## 八、后续步骤

配置完成后，继续以下工作：

1. **启用域名校验** - 修改 `project.config.json` 中 `urlCheck: true`
2. **提交审核** - 在微信公众平台提交代码审核
3. **发布上线** - 审核通过后发布
