# 快速解决域名检查问题 🚀

## 📌 问题简述
您看到的错误：
```
request:fail url not in domain list
```

这是因为微信小程序默认开启域名检查，只允许请求白名单中的域名。

## ✅ 解决方法（仅需3步）

### 第1步：打开开发者工具设置
在微信开发者工具右上角，点击 **详情** 按钮（齿轮图标）

### 第2步：关闭域名检查
1. 点击 **本地设置** 标签
2. ✅ **勾选** 这一行：
   > 不校验合法域名、web-view（业务域名）、TLS版本以及HTTPS证书

### 第3步：清除缓存并重启
1. 点击顶部菜单 **工具 > 清缓存 > 清除全部缓存**
2. 关闭微信开发者工具
3. 重新打开项目

## 🧪 验证方法

现在您可以直接使用问卷功能测试 API 连接：

1. **打开项目** - 进入"首页" → 点击"开始分析"
2. **输入问题** - 在问卷页面输入第一个问题答案
3. **查看状态** - 观察状态栏是否显示"✓ 真实AI已响应"
   - ✅ 显示成功 -> 配置完成！
   - ❌ 仍然失败 -> 请检查是否按步骤勾选了选项

## 📝 常见问题

### Q1: 为什么设置后还是失败？
- 确认勾选的选项名称是否正确
- 确认是否清除了缓存
- 确认是否重启了开发者工具

### Q2: 这个设置安全吗？
- 这只是开发时的临时设置
- 发布到正式环境时需要在微信公众号后台配置域名白名单

### Q3: 如何恢复正常的域名检查？
- 取消勾选"不校验合法域名..."即可恢复
