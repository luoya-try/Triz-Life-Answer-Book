### 1. 域名白名单配置（必须）

按照 `docs/微信域名配置指南.md` 中的步骤：

1. 登录 [微信公众平台](https://mp.weixin.qq.com/)
2. 进入 **开发 > 开发管理 > 开发设置 > 服务器域名**
3. 在 **request 合法域名** 中添加：
   ```
   https://integrate.api.nvidia.com
   ```

4. 保存配置（10分钟内生效）

## ⚠️ 重要提醒

### 域名配置是阻塞项

**在配置域名白名单之前**：
- 小程序无法调用AI API
- 生产环境无法正常工作
- 提交审核可能因"域名不合法"被拒绝

### 操作顺序

```
1. 本地开发测试
2. 配置域名白名单 ⚠️（必须）
3. 启用域名校验（已完成）
4. 真机调试测试
5. 提交审核
```

### 常见问题

**Q: 域名配置后多久生效？**
A: 10分钟内生效

**Q: 配置后还需要做什么？**
A: 在微信开发者工具中取消"不校验"选项，然后真机测试

**Q: 提示域名不合法怎么办？**
A: 检查域名拼写，确认包含 `https://`
