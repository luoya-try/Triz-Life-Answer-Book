# 接入大模型接口实现智能引导方案

## 一、方案概述

为了实现问卷页面的智能引导功能，需要接入大模型接口，根据用户前i-1个问题的答案生成更具人情味和针对性的提示语。

## 二、技术选型

### 1. 大模型选择

推荐以下几种大模型API：

* **OpenAI GPT-3.5/4**：功能强大，生成质量高

* **百度文心一言**：中文支持好，响应速度快

* **阿里通义千问**：中文理解能力强，适合专业领域

* **腾讯混元大模型**：与微信生态兼容性好

### 2. 接入方式

**方案A：直接调用API（推荐）**

* 在微信小程序管理后台配置request合法域名

* 使用wx.request直接调用大模型API

**方案B：使用云函数作为中间层**

* 部署云函数调用大模型API

* 小程序调用云函数获取结果

* 优势：更安全，无需暴露API密钥

## 三、具体实现步骤

### 1. 准备工作

**方案A：直接调用API**

1. 注册大模型API账号，获取API密钥
2. 在微信小程序管理后台，添加API域名到request合法域名
3. 在小程序代码中安全存储API密钥（建议使用环境变量或云开发）

**方案B：使用云函数**

1. 注册大模型API账号，获取API密钥
2. 在微信云开发控制台创建云函数
3. 在云函数中配置API密钥和调用逻辑

1. **修改updateQuestionHint函数**

```javascript
// 更新问题提示
updateQuestionHint: function() {
  const questions = [...this.data.questions];
  const answers = this.data.answers;
  const currentQuestion = this.data.currentQuestion;
  
  // 如果是第一个问题，使用默认提示
  if (currentQuestion === 1) {
    this.setData({ questions });
    return;
  }
  
  // 准备上下文信息
  const context = this.prepareContext(answers, currentQuestion);
  
  // 调用大模型生成提示
  this.generateHintWithAI(context, currentQuestion, questions);
},

// 准备上下文信息
prepareContext: function(answers, currentQuestion) {
  const context = [];
  
  // 添加核心问题
  if (answers[0]) {
    context.push(`核心问题：${answers[0]}`);
  }
  
  // 添加之前回答的问题
  for (let i = 1; i < currentQuestion - 1; i++) {
    if (answers[i]) {
      context.push(`${this.data.questions[i].shortText}：${answers[i]}`);
    }
  }
  
  return context;
},

// 调用大模型生成提示
generateHintWithAI: function(context, currentQuestion, questions) {
  const currentQuestionData = questions[currentQuestion - 1];
  
  // 构建提示模板
  const prompt = `用户正在回答TRIZ问卷，当前问题是："${currentQuestionData.text}"。\n
用户之前的回答：\n${context.join('\n')}\n
请根据用户之前的回答，为当前问题生成一个友好、针对性的提示语，鼓励用户提供更多背景信息。提示语应该：\n1. 自然、有人情味\n2. 提及用户之前的回答内容\n3. 引导用户从问题的角度思考\n4. 简洁明了，不超过100字\n
例如："您刚才提到核心问题是'电池续航短'，那么在当前，是什么更大的系统（超系统，比如您的日常通勤环境）限制了电池的表現呢？"`;
  
  // 调用大模型API
  this.callLLMAPI(prompt, (hint) => {
    questions[currentQuestion - 1].hint = hint;
    this.setData({ questions });
  });
},

// 调用大模型API
callLLMAPI: function(prompt, callback) {
  // 方案A：直接调用API
  wx.request({
    url: API_CONFIG.apiUrl,
    method: 'POST',
    header: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${API_CONFIG.apiKey}`
    },
    data: {
      model: 'gpt-3.5-turbo',
      messages: [
        { role: 'system', content: '你是一个TRIZ问题分析专家，擅长引导用户思考问题' },
        { role: 'user', content: prompt }
      ],
      max_tokens: 150
    },
    success: (res) => {
      const hint = res.data.choices[0].message.content;
      callback(hint);
    },
    fail: (err) => {
      console.error('调用大模型API失败：', err);
      // 失败时使用默认提示
      callback('请详细描述您的情况，这将帮助我们更好地分析问题。');
    }
  });
  
  // 方案B：使用云函数
  /*
  wx.cloud.callFunction({
    name: API_CONFIG.cloudFunctionName,
    data: { prompt: prompt },
    success: (res) => {
      const hint = res.result.hint;
      callback(hint);
    },
    fail: (err) => {
      console.error('调用云函数失败：', err);
      callback('请详细描述您的情况，这将帮助我们更好地分析问题。');
    }
  });
  */
}
```

### 3. 云函数实现（方案B）

**创建云函数generateHint**

```javascript
// cloudfunctions/generateHint/index.js
const cloud = require('wx-server-sdk');

cloud.init({
  env: cloud.DYNAMIC_CURRENT_ENV
});

exports.main = async (event, context) => {
  const { prompt } = event;
  
  try {
    // 调用大模型API
    const res = await cloud.fetch({ // 或使用其他HTTP库
      url: 'https://api.openai.com/v1/chat/completions',
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${process.env.OPENAI_API_KEY}`
      },
      data: {
        model: 'gpt-3.5-turbo',
        messages: [
          { role: 'system', content: '你是一个TRIZ问题分析专家，擅长引导用户思考问题' },
          { role: 'user', content: prompt }
        ],
        max_tokens: 150
      }
    });
    
    const hint = res.data.choices[0].message.content;
    return { hint };
  } catch (error) {
    console.error('调用大模型API失败：', error);
    return { hint: '请详细描述您的情况，这将帮助我们更好地分析问题。' };
  }
};
```
